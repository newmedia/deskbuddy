deskbuddy.dev installeren

Zet de firmware op je Waveshare ESP32-S3-Touch-AMOLED-1.75, direct vanuit je browser. Je hebt alleen een USB-kabel nodig.

Deze browser kan het niet

Installeren via USB werkt met Web Serial, en dat bieden alleen Chrome, Edge en Opera op een computer (Windows, macOS, Linux of ChromeOS). Firefox, Safari en telefoons ondersteunen het niet.

Liever zelf flashen? Download firmware.bin van de releases en gebruik esptool.

Installeren

Open deze pagina in Chrome of Edge op een computer. Open deze pagina via https om te installeren.
  1. Sluit de deskbuddy met een USB-C-kabel aan op je computer (een kabel die ook data kan, niet alleen laden).
  2. Klik op Verbind en installeer en kies de poort USB JTAG/serial debug unit.
  3. Wacht tot het klaar is (ongeveer een minuut). De deskbuddy start daarna vanzelf opnieuw op.

Let op

Hiermee vervang je de firmware op het apparaat. Staat er nog de originele firmware op en wil je die behouden, maak dan eerst een backup van de flash (zie docs). Daarna kun je niet meer terug zonder die backup.

Je Wi-Fi-gegevens en instellingen blijven bewaard als er al een deskbuddy-firmware op stond.

Lukt het niet?

  • Geen poort in de lijst: probeer een andere kabel of USB-poort. Houd anders BOOT ingedrukt terwijl je de USB-kabel aansluit en probeer opnieuw.
  • Linux: je gebruiker moet in de groep dialout zitten.
  • Daarna updaten? Dat kan vanzelf: de deskbuddy haalt nieuwe versies zelf van GitHub (zie de README).
